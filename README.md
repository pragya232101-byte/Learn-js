JAVASCRIPT LAB — INTERACTIVE LEARNING WEBSITE

HOW TO RUN
1. Extract JavaScript-Lab-Website.zip.
2. Open the javascript_lab folder.
3. Open index.html in Chrome, Edge or Firefox.

INTERNET
The site loads Google Fonts, jQuery 3.7.1 and jsPDF from CDNs. Most native JavaScript lessons work offline. jQuery demonstrations and the in-site PDF download require internet access.

FEATURES
- 12 lessons covering JavaScript, DOM, jQuery, dynamic webpages, setTimeout, clearTimeout, setInterval and interval animation.
- Interactive DOM, jQuery and timing demonstrations.
- Editable HTML/CSS/JavaScript playground with sandboxed iframe preview.
- Seven-question quiz with explanations.
- Lesson progress and theme saved in localStorage.
- Downloadable PDF notes.
